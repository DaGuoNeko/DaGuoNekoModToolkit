# BB 测试机器人

使用 Blockbench 5.2.1 实际创建并导出，供“大果喵模组工具箱”的模型拓展包功能测试。

## 最快测试方式

在工具箱点击“打开工程”，选择 `bb_test_robot.dgnproject`，进入“NPC模型拓展”后导出 ZIP。
工程已包含两套贴图、预览图、模型及动画；不依赖原始素材路径。

## 手工添加模型

- 显示名称：BB 测试机器人
- 自定义模型 ID：bb_test_robot（不填写 `_dlcnpc` 后缀）
- 模型文件：bb_test_robot.geo.json
- 贴图按顺序添加：robot_orange.png、robot_blue.png
- 预览图：preview.png
- 动画资源：bb_test_robot.animation.json
- idle：animation.bb_test_robot.idle
- walk / walka：animation.bb_test_robot.walk
- attack：animation.bb_test_robot.attack
- death：留空，使用工具箱默认死亡动画
- 皮肤变体：0=橙色机甲，1=蓝色机甲
- 碰撞箱：宽 0.9，高 1.85；允许装备附件关闭

`软件测试配置.json` 提供完整字段参考。

## 文件说明

- bb_test_robot.bbmodel：可在 Blockbench 继续编辑的原工程，包含嵌入贴图与动画。
- bb_test_robot.geo.json：Bedrock geometry，7 个骨骼、15 个 cube，128×128 UV。
- bb_test_robot.animation.json：idle / walk / attack 三个动画。
- bb_test_robot_模型拓展包.zip：由当前软件发布后端实际制作的行为包+资源包测试成品。
- bb_test_robot.dgnproject：可直接打开的工具箱工程。

测试成品实体 ID：`customnpc:bb_test_robot_dlcnpc`。

已验证：Blockbench 导出、骨骼层级、UV 边界、动画骨骼引用、后端保存/导出、工程重开、拓展 ZIP 导入、两个贴图变体，以及 JSON/Python 的 UTF-8 无 BOM。
尚未验证：Minecraft 游戏内的动画、AI、碰撞和实际渲染。纹理是可辨识的程序绘制测试配色。
