# 大果喵模组工具箱

**DaGuoNeko Mod Toolkit** 是一款面向网易《我的世界》模组创作者的资源制作工具，用来整理皮肤、模型、贴图和音效，并导出可供配套模组使用的拓展包。

当前版本：**3.0.0** · [下载软件](https://github.com/DaGuoNeko/DaGuoNekoModToolkit/releases/tag/v3.0.0) · [更新内容](CHANGELOG.md)

通过可视化界面完成素材导入、预览、编辑和打包，减少手工整理文件与填写配置的步骤。

## 主要功能

- **NPC皮肤拓展**：通过“添加皮肤”选择一张或多张 PNG，编辑名称和作者，为 NPC 选择皮肤或指定模型贴图，导出 NPC皮肤拓展包。点击缩略图或操作区的“查看”按钮可预览皮肤。
- **3D 皮肤预览**：旋转、缩放查看标准人型皮肤，切换 Steve / Alex 手臂，直观检查皮肤效果。
- **NPC模型拓展**：整理模型、贴图和动画，配置皮肤变体、碰撞箱及附件，制作 NPC模型拓展包。
- **贴图拓展**：批量整理图标、横幅和装饰贴图，设置名称、分类与搜索关键词，供大果喵前置组件的资源选择器使用。
- **音效拓展**：导入和试听 OGG Vorbis 音效，设置分类、音量和音调，制作可在前置组件中选择的音效拓展包。
- **工程保存**：将四种资源列表和关联素材一起保存为 `.dgnproject` 工程，方便下次继续编辑或转移到其他电脑。
- **拓展包导入**：导入已有拓展包继续编辑；贴图与音效支持导入本工具生成的包，模型支持的导入范围以软件提示为准。
- **界面设置**：支持浅色、深色、跟随系统主题，以及强调色和背景图片设置。背景覆盖整个窗口，居中等比铺满；可调整透明度、模糊度和缩放比例，设置自动保存。
- **输入提示**：必填项、名称与 ID 格式、版本号或数值范围不符合要求时，输入框会显示红色边框和具体原因，修正后自动恢复。
- **下拉搜索**：所有下拉框支持按名称或 ID 搜索选项，可使用方向键和回车选择。
- **页面切换**：按侧栏顺序上下滑动衔接，快速切换时响应最后一次选择；尊重系统的“减少动态效果”设置。

## 怎么使用

四个制作页面的标题区均有“帮助”按钮，可在浏览器中打开对应的使用文档。

四个页面也各有“新建项目”按钮，用于重置当前页面。贴图和音效项目会同时恢复包设置、重新生成包标识与全部 UUID；NPC皮肤和模型项目会清空条目及导入配置。其他页面的数据、源素材和已保存工程不受影响。开始新项目之前，请先保存需要保留的内容；“清空列表”只清除条目，贴图/音效包的标识和设置仍保留。

1. 完整解压软件压缩包，运行 `DaGuoNeko-Mod-Toolkit.exe`，请保留同目录下的其他文件。
2. 选择“NPC皮肤拓展”“NPC模型拓展”“贴图拓展”或“音效拓展”，添加对应素材。
3. 编辑名称、分类及相关选项，预览或试听资源。
4. 保存工程，或导出 ZIP 拓展包，在游戏地图中加载对应内容。

也可将文件直接拖入制作页面：NPC皮肤与贴图页面支持 PNG，音效页面支持 OGG，NPC模型页面支持一个模型 JSON 和配套 PNG、动画文件（动画使用 `.animation.json` 或 `.animations.json` 后缀）。模型编辑窗口可继续拖入素材，文件选择框也支持拖入对应文件。

模型编辑时，“自定义模型 ID”填写 `forest_guard` 这样的自定义部分，软件生成完整 ID `customnpc:forest_guard_dlcnpc`。模型分类可选择“原版”“其他”“功能性”，决定其在 NPC 模型选择列表中的分组，新建模型默认“其他”。导入动画 JSON 后，实体动画下拉框和可选动画列表自动读取文件中的动画 ID；可分别设置 idle（待机）、walk（行走）、walka（跑步）、attack（攻击）、death（死亡），也可选择 pass（无动作）。留空使用各字段提示的默认动画。

编辑已有模型时，默认保留原可选动画列表（包括手工筛选、顺序、内置动画引用和空列表）。需要改用文件中的全部动画时，勾选“跟随动画文件更新可选列表”；新建模型默认勾选。实体动画下拉框始终显示文件中的动画 ID。

模型添加或拖入 PNG 时，自动登记对应的可切换皮肤，名称沿用贴图名称，作者可在“皮肤变体”中填写。旧模型可点击“补齐贴图变体”补上缺失条目，已有变体信息保留。通过“默认贴图”选择新建 NPC 的默认外观；所选贴图会排到 `skinid 0`，其他贴图及变体编号同步重排。更改默认贴图后，原有 NPC 的已存皮肤编号仍沿用新顺序，需按需要重新选择。

四个页面均支持拖入一个 ZIP 拓展包进行导入，或一个 `.dgnproject` 工程进行恢复；替换现有列表前会确认。请勿把压缩包、工程与素材混在一次拖入中。不支持的格式或文件夹会提示原因。

NPC皮肤拓展和NPC模型拓展用于配套的 **customNPC 模组**。贴图和音效拓展需要同时加载生成的行为包、资源包与支持资源选择器的 **大果喵前置组件**。

音效目前支持 **OGG Vorbis**；其他格式请先转换。退出软件前请保存工程，以便下次恢复编辑。

## 模组开发者工具

开发者工具默认隐藏，可在 **设置 → 功能显示 → 显示模组开发者工具** 中开启，软件会记住开关状态。

- **3D 文字**：通过浏览器打开在线文字制作工具。
- **开发者工具箱**：启动网易开发版游戏，调用已配置的外部工具生成模组框架和物品模板。
- **MCStudio 项目**：查看账号与项目，管理项目路径、测试存档和游戏版本。
- **存档全局配置**：按客户端和玩家查找配置文件，也支持直接浏览 `users/config` 目录，快速打开或定位文件。
