# NPC 模型拓展包：在线动画支持

新版模型拓展导出会自动生成在线动画适配资源，无需另外勾选，也不依赖本机安装 Python。

1. 在“NPC模型拓展”中添加模型、贴图和已有资源动画，或导入旧的模型拓展 ZIP。
2. 完成模型配置并导出 ZIP。导出器读取最终的实体与几何资源，生成完整骨架、世界/纸娃娃驱动和预览副本。
3. 将导出的行为包、资源包与支持模型动画注册的新版“自定义NPC”主包一起加载。生成脚本自动在两端注册，不需要修改主包骨架文件。
4. 加载“自定义NPC动画”附属包后，打开动画编辑器，选择该拓展模型，制作并保存动画。
5. 使用 `/cnpc:anim` 或 NPC 的七状态动画配置播放。

原有 `animation_list` 继续用于资源动画选择，与在线编辑动画的骨架适配分别保留。重新导入工具再导出时，自动生成资源按包内清单识别并重建，不把旧载体当成用户动画重复打包；用户的实际动画、贴图和模型仍保留。

骨骼或必要的资源引用无效时导出会明确失败。主包版本过旧时，拓展仍可注册原模型目录，但会提示在线动画需要升级；不要将这个提示当作在线功能已经接入。

同一实体标识的旧、新拓展包不要同时加载。修改骨架后需要重新导出并完整重载资源，不能只替换索引；多几何接管冲突仍受主包校验限制。

文本输出沿用 UTF-8 无 BOM，随机配置文件名仍保持原有限制。此说明不表示所有模型已经逐一完成真实游戏测试。
